# Profile Pictures

Place your 1:1 ratio (square) profile picture images in this folder.

After adding images here, copy them to:
```
frontend/codes/public/profile-pictures/
```

They will be served at runtime and appear in the profile picture picker in the sidebar.

**Supported formats:** PNG, JPG, JPEG, WEBP
**Recommended size:** 200x200 px minimum, 1:1 aspect ratio

**Naming convention:** avatar-1.png, avatar-2.png, etc.
