## 9. Architectural Blueprint for the New Pipeline

Based on Requirements R1–R4, the standalone pipeline should be modularized cleanly under `src/services/` or `src/pdf-pipeline/`:

1. **Targeted PDF Extractor (`src/services/pdf/pdf-extractor.js`)**
   - Reads PDF binary buffer / file path.
   - Extracts page-by-page text.
   - Filters pages and sentences matching targeted keywords (e.g., `["eligibility", "age limit", "educational qualification", "nationality", "fee", "closing date", "dates"]`).
   - Minimizes tokens and strips redundant boilerplate while preserving page number attribution.

2. **Gemini Extraction Service (`src/services/ai/gemini-parser.js`)**
   - Uses `@google/genai` (`const { GoogleGenAI } = require('@google/genai')`).
   - Sends targeted text with a strictly typed JSON schema / prompt.
   - Receives structured criteria (e.g. `minAge`, `maxAge`, `categoryRelaxations`, `requiredEducation`, `eligibleDegrees`, `applicationDeadline`, `nationality`).
   - Implements offline mock mode for testing without a live Gemini key.

3. **Unity Checker / Rule Validator (`src/services/validator/unity-checker.js`)**
   - Compares Gemini structured data against mock database candidate criteria / rules.
   - Evaluates:
     - Age eligibility (including category relaxation: General, OBC, SC, ST, EWS).
     - Educational qualification match (degree / minimum level).
     - Deadline validity (closing date check).
     - Citizenship / nationality criteria.
   - Outputs comprehensive match verdict (`isMatch: boolean`, detailed per-rule pass/fail breakdown, and textual summary).

4. **Standalone CLI Runner (`parse-demo.js`)**
   - Standalone execution script in root: `node parse-demo.js [options]`.
   - Supports options: `--pdf <path>`, `--keywords <kw1,kw2>`, `--mock-criteria <path>`, `--mock-gemini`.
   - Logs:
     - PDF load and targeted extraction metrics (total pages vs extracted pages/sentences, token reduction).
     - Gemini structured output.
     - Unity check evaluation table and final eligibility verdict.
   - **Zero dependency** on Firestore, user creation, or Resend.

5. **Automated Unit & Integration Tests (`test/pdf-pipeline.test.js`)**
   - Validates targeted keyword extraction, sentence parsing, unity checking logic, and CLI runner execution with `node --test`.
